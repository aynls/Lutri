# 图库与本地存储

图库以 asset ID 管理原图。图板、标签、收藏和历史引用不复制图片；历史删除不会删除图库资产。标签不提供自动清理保护，收藏和任意图板成员关系继续提供保护。

## 查询与浏览

图库在 SQLite 中筛选、排序、计数并分页，每页 80 项。支持模型、供应商、来源、文件状态、标签、日期和方向组合查询，按日期、名称或文件大小排序。新资产在入库时记录字节数；旧资产可通过“检查文件”补齐。

“选择已加载”只选择当前已加载的图片；“选择全部匹配项”取得当前查询的 ID 集合，随后执行操作。更换筛选条件清空选择。图板内的“移动到图板”原子地移除当前图板并加入目标图板，不改变其他归属。

查看器每次打开时取得独立的有序 ID 集合，在该集合内前后浏览。新图片不会挤乱现有查看器的顺序；缺失图片仍保留缺失位置。修改收藏、删除、迁移等操作通过应用事件通知其他窗口刷新。

草稿、创作卡片和正在执行的任务按 ID 缓存所需资产；历史按当前页查询其关联资产。当前图库页没有加载某个 ID，不代表图片丢失。

## 来源与标签

资产的最小来源信息包括导入／生图／超分、模型、供应商和任务 ID。来源不是可恢复的请求参数，完整参数仍由历史管理。启动时从尚存历史回填可靠的生成来源；无法恢复的信息保持未知。

标签支持批量添加、移除、全局重命名和删除。图板组织项目，标签用于跨项目检索。标签变化不会改变默认来源库。

## 目录迁移

数据库、设置和任务暂存文件保留在应用数据目录。可迁移的内容是受管原图与缩略图。目录定位文件为 `library.json`；迁移日志为 `library-migration.json`。数据库版本为 2，原有 JSON 记录保持兼容。

迁移复制每个受管文件，校验复制内容，然后在数据库事务中切换路径，更新目录定位，最后清理旧的已登记文件。文件复制使用临时文件再重命名；中断后可重试相同目标。启动时根据数据库中提交的位置记录恢复目录定位，不把未完成复制当作迁移成功。

迁移与资产写入、图库修改及维护使用同一互斥边界；超分任务的接纳也受该边界保护。超分存在任务时禁止迁移。迁移后的目录按需授权给图片协议，只允许访问图库的原图和缩略图子目录。

已配置目录不可用时，不自动创建空库，也不将整库当作自动清理对象。清理缺失条目前必须先检查文件并人工选择。维护保留历史中的缺失引用。重建缩略图支持位图和 SVG。

## 导出

“另存为”使用默认导出目录并记住最近位置。自动导出按生图、超分分别启用，默认关闭；不会改变图库入库和超分“是否保存到图库”的选择。

自动导出使用资产或结果 UUID 命名，已有相同内容时视为完成，不覆盖不同内容。导出错误与生成、推理结果分开处理，可以单独重试。图库自动清理不删除外部导出的副本。

复制图片通过系统剪贴板写入像素；SVG 按完整尺寸栅格化后复制。

## 验证范围

本轮使用 TypeScript／Vite 构建、Rust 静态检查及格式检查，不添加或运行测试。迁移中断恢复、多个窗口的完整交互、操作系统剪贴板及外部磁盘行为仍需要桌面验收；静态检查不代表这些运行行为已验证。
