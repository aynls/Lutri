# Lutri 产品需求

Lutri是面向专业创作者的桌面AI生图工作台。
包含创作、超分辨率、任务和图库四大核心功能。"任务"同时承载生图任务进度和历史记录。

## 创作

用户选择模型和供应商后开始创作。创作页提供"常规"和"批处理"两个工作视图，共用左侧的提示词、参考图和参数编辑器，视图切换位于左侧面板顶部。

常规视图右侧为瀑布流，主操作为"开始生成"；批处理视图右侧为待提交清单，编辑器主操作为"加入清单"，清单底部提供"提交批处理"。切换视图时保留提示词和参考图，尽力保留参数；当前组合不支持批处理时，自动选择可用的批处理组合（优先同一模型下已配置的供应商，其次最近使用的组合）。

### 常规生成

瀑布流每张卡片对应一张图片，一次生成多张时创建多个卡片。生成中显示加载动画和已耗时计时；取得结果后进入下载，显示"正在下载"及各图下载状态，下载失败的图片提供重试。

请求区分提交中、提交结果未知、生成中、结果获取失败、结果下载中、结果下载失败、已完成和生成失败等状态。轮询中断或超时但供应商仍有未取得的结果时显示"结果获取失败"，已有图片保留，重试继续查询原任务。"重试"只继续获取原任务的结果，不创建新的生成任务；无法查询原任务或取得结果时显示原因。

点击卡片在模态弹窗中查看图片和相关信息，支持左右切换。卡片可移除，移除不删除图库资产或历史记录，也不取消后台任务。瀑布流最多保留最近200张图片的卡片，超出时较早卡片自动退出。

### 模型与供应商

同一模型在不同供应商下可能支持不同的字段、取值、默认值和能力。界面按"模型 × 供应商"组合提供输入项，例如提示词、参考图、输出尺寸、审核容忍度、联网搜索等。填写必要参数并满足约束后方可提交，可选字段按组合规则使用默认值或省略。

对生成和编辑路径分离的组合，提供"创作方式"选择，新草稿默认"生成"；"自动"按输入分流。"生成"将输入图用于参考创作；"编辑"选定一张原图进行编辑，其他输入图作为参考。切换方式保留已有输入，不兼容的设置须修正后才能提交。统一接口且没有独立操作能力的组合不显示此控件。创作方式与原图绑定随草稿和历史保存。

"请求次数"是重复执行设置，决定当前配置发送多少次相同参数的请求；"单次生成数量"是模型原生参数，按组合约束展示和校验，不支持时不显示。

参考图默认以"参考图"为别名，可随时重命名；提示词中可一键插入别名，并以胶囊样式显示。参考图顺序有意义，重排时同步提示词、区域和蒙版中的图片引用；引用的图片丢失时，对应区域或蒙版一并移除并提示用户。提交时若提示词引用了不存在的参考图，显示警告弹窗。

### 批处理

批处理用于积累多组提示词或参数后统一提交，目前支持 Google 和 OpenAI 的原生异步批处理。只有官方支持批处理的"模型 × 供应商"组合可选。

待提交清单是按加入顺序排列的批处理草稿。"加入清单"保存当前提示词、参考图及绑定关系、模型、供应商、参数和请求次数的独立副本；加入后编辑器内容保留供继续修改，不影响已加入条目。草稿及未加入清单的编辑内容自动保存，关闭应用后可恢复。

### 提示词生成

提示词编辑框旁常驻"生成"按钮，点击进入提示词生成页面。该页面与创作页共用当前草稿，编辑提示词和参考图会直接更新草稿。每张生成结果卡片保留请求时的提示词和参考图快照；采用结果时更新当前提示词，若快照中的参考图已从草稿移除，须经用户确认后补回。

发送给 LLM 的内容包括应用维护的系统提示词、当前提示词和参考图，以及可选的附加规范。系统提示词不展示、不提供编辑入口。应用内置若干生图模型系列的提示词最佳实践，用户也可导入自己的 `.md` 规范文件；每次最多选择一份规范，其内容作为写作参考追加到请求末尾。

用户管理一个"作家队列"，包含一个或多个模型配置，可重复。每次请求每个作家撰写一份提示词，以多个卡片展示，支持推理过程和生成内容的流式显示。卡片可让对应作家重写，或确认采用该提示词。作家配置支持检测模型可用的思考强度档位并选择使用，检测不到时按不支持处理。

Writer 仅支持具备图片输入能力的模型；已添加的参考图会发送给所有作家，并要求 LLM 在输出中保留图片引用标记。

## 超分辨率

默认单图模式：右侧显示图片，左侧工具栏选择模型、倍率和自动另存为设置。可切换到批处理模式，右侧变为多张图片的卡片网格，各卡片进度独立。

单图完成后可拖动手柄查看前/后对比；批处理卡片打开图片查看器，支持批次内切换、缩放和完成后的拖动对比，未完成时显示原图与当前任务状态。

SVG 不支持超分辨率，图库、查看器和超分页的添加入口均不接受 SVG。

超分结果自动保存为新的本地图片资产，通过收藏或加入图板纳入图库。单图、批处理卡片和查看器均可将完成的结果直接用作创作参考图，无须先加入图库。

已取消或失败的任务点击重试后立即重新加入队列。超分辨率任务不进入"任务"页面。

## 任务

"任务"页面同时展示进行中的任务和历史记录，提供"常规"和"批处理"两个标签，各自独立查询并保留筛选条件与滚动位置。两个标签均支持按时间、模型、供应商、状态、提示词和 asset ID 查询。

历史记录通过 asset ID 引用图片并保留用途、顺序和绑定关系，不保存图片副本；源文件丢失时显示占位和提示。用户可一键恢复历史请求参数，包括仍可访问的参考图；缺失的图片保留原位置和缺失占位并明确提示，其绑定的区域或蒙版设置一并移除。

批处理支持将所选配置重新加入清单，新草稿与原任务记录独立；仅重新加入生成失败项时按失败请求数建立条目，不重复加入已成功的请求。

任务记录可查看状态并继续获取原任务结果，即使对应卡片已退出瀑布流。

按 asset ID 搜索可匹配记录中的参考图或生成结果；从图库图片可"查找相关历史"，进入任务页并自动按该 asset ID 查询，切换标签时保留查询条件，无匹配时显示空结果。

## 图库

图库由"收藏"和用户自定义图板组成，仅展示已收藏或已加入图板的图片。生图、超分结果和外部导入的图片均可纳入图库；图片来源与图库归属独立，用作参考图不改变其来源或归属。

从外部导入的图片复制到本地资产目录，每个图片资产由唯一的 asset ID 标识，可一键复制。图片不保存名称，界面不显示标题，仅支持按 asset ID 搜索。在图库中导入的图片自动加入当前收藏或图板。

创作时从外部添加的参考图先暂存为草稿素材，提交常规生成或批处理时转为持久资产；加入批处理清单本身不改变素材的暂存状态。这些操作不自动将图片纳入图库，用户可通过收藏或加入图板保留图片。

生图结果自动保存为本地图片资产，可在任务详情、查看器和常规生成的瀑布流中查看，也可复制、另存为和用作参考图。结果通过收藏或加入图板纳入图库，未纳入图库的结果按本地文件清理规则保留；批处理结果不进入瀑布流。

"自动另存为"用于在本地资产之外额外保存结果副本，位于常规生成和超分辨率主按钮上方；批处理使用清单底部的整批设置。该选项默认关闭，开启后展开目录选择，未选目录时禁止提交。常规生成、批处理和超分辨率分别保存开关状态，共用另存为目录。提交时固定另存为目录，每张结果保存后按设置复制，另存为失败可单独重试。收藏和图板操作不影响自动另存为。

图片的历史请求参数保存在任务记录中。图片查看器找到对应生成任务后，可直接查看请求详情并恢复参数；图片也提供"查找相关历史"入口，在任务页查询相关记录并恢复。

本地文件自动清理默认关闭，开启后按保留天数清理生成结果，默认保留30天，可设为1–3650天的整数。已收藏、属于任意图板或正在使用的资产不会被清理；外部导入的素材不参与自动清理。保留期从资产创建时计算，资产失去最后一项收藏或图板保护后重新计时。历史记录不作为长期保留依据，文件清理后对应图片显示缺失占位。设置中可查看并手动清理未受保护且未使用的本地生成结果和导入素材。

## MCP

应用为 agent 提供模型与参数查询、普通创作和原生云端批处理提交、任务与结果查询、原任务结果恢复、图片导入和图库资产检索。资产检索仅覆盖已收藏或已加入图板的图片，其他已保存资产可通过 asset ID 读取。Writer 和超分辨率不提供 MCP 工具。服务仅监听本机地址并使用 token 鉴权。

## 界面

统一深色界面，提供暖砂、素灰、雾蓝、青瓷四种主题和赤陶、石墨、黛蓝、苔绿、琥珀、湖青、鸢紫、蔷薇八种强调色，主题与强调色独立选择并保存；不提供浅色模式或跟随系统切换。动画遵循系统减少动态效果的偏好。控件简洁、术语统一，返回和关闭入口持续可见；UI 文案保持精炼，不使用解释性文字。
