# Seedream 5.5 API（BytePlus）

BytePlus 的模型 ID 为 `dola-seedream-5-5-261028`，默认地址为 `https://ark.ap-southeast.bytepluses.com`。Lutri 使用 BytePlus 的地址和 API key 调用 `POST /api/v3/images/generations`。

生成和编辑支持最多 10 张参考图、自定义宽高和透明 PNG。拆层使用一张源图，最多输出 1 张底图和 99 个像素图层。请求字段、尺寸校验和 PNG、PSD 交付与火山方舟适配相同。
