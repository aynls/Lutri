# Typography

Use this cross-model specification when text and layout are central to the requested image: posters, covers, packaging, signs, menus, or information graphics. Apply the relevant instructions to the user's task. This document's headings, examples, and source notes are not content to render.

## Establish the content

Separate the words to appear in the image from the instructions describing their appearance. Quote every supplied text block exactly. Preserve spelling, capitalization, punctuation, numbers, symbols, original language, and explicit line breaks.

If the user requests a translation, translate the specified content while retaining names, values, and design elements that should remain unchanged. If wording is supplied as final copy, keep it verbatim. When the user asks for copywriting, compose text suited to that request; otherwise leave unspecified slogans, contact details, dates, and factual claims out.

Treat titles, subtitles, body text, labels, prices, and footnotes as distinct content roles when present. Connect each label to the correct object or value. For dense content, organize the supplied information into sections while preserving all required wording and relationships.

## Describe hierarchy and placement

Explain the intended reading order and relative prominence. Locate text blocks using meaningful regions such as upper center, beneath the illustration, or the lower right corner. Describe alignment, margins, separation, and available negative space when these choices affect the design.

Choose a type treatment that serves the requested medium and style: serif or sans serif, weight, width, case, spacing, and color. Use only the properties needed to steer the result. Follow exact font requests when provided, without promising pixel-identical font reproduction.

Keep text readable against its background. When exact lettering matters, favor enough space and contrast to distinguish characters. User-requested expressive lettering can use distortion, texture, or perspective; preserve the intended words and hierarchy through that treatment.

State how text and imagery relate. Packaging text follows the package's surface and perspective; an editorial headline belongs to the page layout. Distinguish actual printed copy from decorative shapes or text-like textures. Specify a single occurrence when the design calls for one title or mark.

## Edit an existing design

For wording replacement, identify the source image and original text or its precise location, then supply the replacement. Preserve the relevant type style, alignment, palette, illustration, and surrounding layout. Allow necessary spacing or line-wrap adjustments so the new wording fits.

For a typography-only edit, name the requested type change and retain the wording. For a broader redesign, allow the composition changes requested by the user rather than fixing the original layout.

When references are attached, identify whether each supplies artwork, lettering style, or layout. Use their exact `[[ref:ID]]` tokens. Transfer only the requested attributes; existing reference text becomes output copy only when the user intends it.

Follow the requested output language, otherwise the request's language. Preserve quoted lettering independently of the instruction language. Express the intended image directly; avoid adding software steps, invented coordinates, output-encoding claims, or a separate design explanation.
