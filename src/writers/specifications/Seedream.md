# Seedream

Write prompts for the Seedream 5 family. Use concise, connected language and apply only the sections relevant to the requested task. The headings, examples, and maintenance references below guide writing and are not image content.

## State the visual goal

Describe the subject, action, and setting in a coherent sentence. When known, state the image's use or type, such as a presentation cover, product photograph, poster, or children's illustration. Add style, color, lighting, and composition details where the brief requires control.

For an open-ended idea, choose a few compatible details that support the concept. For a precise brief, preserve its requirements and remove repetition. Keep explicit counts, positions, wording, and relationships. Follow the user's requested output language; otherwise use the language of their request.

Prefer precise style terms and concrete visible features. A longer description is useful for a genuinely detailed scene; simple tasks should remain short. Avoid repeated ornamental adjectives, disconnected tag piles, and generic quality claims.

For an information graphic or educational illustration, identify the visual form, sections, labels, and relationships. Preserve supplied facts and values. Distinguish exact text to print from instructions about how the content should look.

## Make editing instructions unambiguous

Use an operation, a target, and a resulting attribute: add an accessory, remove an object, replace a material, or change a color. Name the target precisely enough to distinguish it from similar elements. Use position, size, clothing, or another visible feature instead of an ambiguous pronoun.

For local edits, state what remains unchanged when it matters to the task. Preserve the relevant pose, expression, surrounding layout, or product details. Allow adjustments needed to integrate the changed element with the existing lighting and perspective.

For reference-based creation, specify what to borrow: character appearance, product features, artistic style, or composition. Preserve those requested attributes while letting the new scene follow the brief.

When the user supplies arrows, frames, or painted annotations to locate a target, refer to the actual visible annotation and its intended operation. Treat annotation-based instructions according to their stated purpose. Preserve supplied region instructions, but never fabricate coordinates, masks, or native API fields.

## Combine references and control lettering

Use the exact supplied `[[ref:ID]]` tokens to identify images. For each relevant reference, state the attributes it contributes and how they combine: a subject in a setting, a person wearing clothing, or a scene using a painting's style. Keep unrelated reference content out of the combination.

Place exact visible text in double quotation marks. Preserve its original language, spelling, punctuation, and specified line breaks. Identify location and hierarchy for titles, captions, or labels; specify typography only as needed.

For a requested series, describe what stays consistent across the images and what changes in each. Distinguish separate images from panels in one composition. Express the user's series intent without inventing image-count parameters or assuming a provider's output limit.
